# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project.

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make the necessary improvements.
4. Test your changes.
5. Commit your changes with a meaningful message.
6. Push your changes to your fork.
7. Submit a pull request.

## Reporting Bugs

If you discover any bugs, please open a GitHub issue describing the problem and the steps required to reproduce it.

## Suggestions

Suggestions for new features, improvements, and enhancements are always welcome.

## Code of Conduct

All contributors are expected to follow the project's Code of Conduct.
