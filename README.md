# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user-provided principal amount, annual interest rate, and time period.

## Description

The Simple Interest Calculator is a command-line application written in Bash. It allows users to calculate simple interest quickly and accurately.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Accepts principal amount from the user.
- Accepts annual rate of interest.
- Accepts time period in years.
- Calculates and displays simple interest.
- Easy to use through a terminal.

## Requirements

- Bash shell
- Linux, macOS, or another environment supporting Bash

## Usage

1. Clone the repository.
2. Navigate to the project directory.
3. Run `bash simple-interest.sh`.
4. Enter the requested values.

## Example

Principal: 10000

Rate: 5

Time: 2

Simple Interest: 1000
